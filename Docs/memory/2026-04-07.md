Added upload history foundations:
- new `GET /api/uploads` summary endpoint backed by `uploads`
- `upload-history.html` operator page with provider/upload/niche/date filters
- nav links added on dashboard, cases, and review queue
- `intake_files` now stores `upload_id` for forward-looking file counts

Legacy assumption:
- historical uploads created before `intake_files.upload_id` linkage may show `file_count = 0` unless their files are backfilled

Billing visibility split:
- operator billing now reads full invoice + revenue detail from `/api/billing/invoices`
- customer billing uses `/api/customer/billing/invoices`
- customer route hides platform fee, clearinghouse cost, and internal margin math

Invoice payment tracking:
- invoices now store `amount_paid`, `remaining_balance`, and `due_date`
- invoice creation defaults to `amount_paid = 0` and `remaining_balance = amount_due`
- billing reads real stored payment totals with safe fallback only for historical invoices missing the new columns
